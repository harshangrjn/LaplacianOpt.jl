# Examples for LaplacianOpt
The `run_examples.jl` driver synthesizes an optimal graph with maximum algebraic connectivity for a given weighted graph. Multiple weighted complete graph instances are available in the `instances` folder. Commercial solvers such as [CPLEX](https://github.com/jump-dev/CPLEX.jl) and [Gurobi](https://github.com/jump-dev/Gurobi.jl) are recommended for the formulated MISDPs with outer-approximation algorithms.
